# アカウント文言の差し替え案（オーナー作業）

2026-09-22 のオーナー決定で、このチャンネルは「自社の豆を紹介する」型から「**誰でも今日すぐ試せる汎用的なコーヒーの抽出知識**」に変わりました。いまの IG プロフィール文は「豆ごとの違いや味を発信」なので、新しい方針と矛盾します。ここに**そのまま貼れる案**を置きます。

**アカウント名（ハンドル・チャンネル名）は変えません。** 変えるのは説明文だけです。
**この変更はオーナーが行います。**（API では変更しません。Claude Routine もここを触りません。）

---

## 1. Instagram プロフィール文（150 字以内）

### 案 A（推し・おすすめ）

```
毎朝ひとつ、家のコーヒーが変わる小さなコツ。
湯温・挽き目・比率・注ぎ方を1本1テーマで。
手持ちの豆と器具でそのまま試せます。
保存して、淹れる前に見返してください。
```

（4 行・68 字）

### 案 B（短く、1 行で伝える）

```
家のコーヒーを1つずつ良くする。湯温・挽き目・比率・注ぎ方を毎朝1テーマ。
手持ちの豆でそのまま試せる数字つき。保存推奨。
```

（2 行・59 字）

**貼り方（スマホ）**
1. Instagram アプリ → 自分のプロフィール → **プロフィールを編集**
2. **自己紹介** の欄の文章を全部消して、上のどちらかを貼り付ける
3. 右上の **完了**（または ✓）を押す

※ 名前（`open_ground_coffee_roasters`）と表示名はそのままにしてください。
※ ウェブサイト欄にショップの URL が入っている場合は、EC が公開されるまで**空のまま**にしておくのがおすすめです（集客フェーズなので、リンク先が無いと離脱の原因になります）。

## 2. YouTube チャンネル説明文

```
家のコーヒーを、今日ひとつだけ良くするチャンネルです。

湯温・挽き目・粉と湯の比率・抽出時間・注ぎ方・器具の違い——
味を決める要素をひとつずつ取り上げて、1本1テーマで解説します。

・毎朝1本、60秒以内
・そのまま真似できる数字つき（粉の量、湯量、湯温、時間）
・手持ちの豆と器具でできることだけ
・「酸っぱい」「苦い」「薄い」の直し方も

器具を持っていない方向けの回もあります。
保存して、淹れる前に見返してください。
```

**貼り方（PC）**
1. [YouTube Studio](https://studio.youtube.com) を開く
2. 左メニューの **カスタマイズ** → **基本情報** タブ
3. **説明** の欄の文章を全部消して、上を貼り付ける
4. 右上の **公開** を押す

※ チャンネル名（`OPEN GROUND coffee roasters`）は変えません。

## 3. あわせて確認したいこと（任意・オーナー判断）

| 項目 | いまの状態 | 提案 |
|---|---|---|
| IG のウェブサイト欄 | ショップ URL が入っている可能性あり | EC 公開まで空にする |
| IG のカテゴリ / ビジネス情報 | 「コーヒーショップ」等 | そのままで問題なし（名前は変えないため） |

| 動画フッターの `OPEN GROUND COFFEE ROASTERS` 表記 | 入っている | 残す / 外す をオーナーが決める（`src/cards/primitives.tsx` の `Brand`。外す場合は PR で） |

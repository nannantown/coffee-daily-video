# 見た目の作り直し — 方向性 3 案（2026-09-26）

オーナー指摘「サムネイルにレシピの細かい数字が入っていて情報が多すぎ、パッと何の話か分からない」「今のスタイルじゃダメ」を受けた 3 案。
**3 案とも中身の考え方は同じ**で、見た目の味付けだけが違う。

- 表紙 = 大きい一言（話題）＋ 1 枚の絵 ＋ 味がどう変わるかの一言。**g・ml・秒・比率の数字は出さない**
- 回ごとに「話題の色」が変わる（湯温＝朱、挽き目＝からし色、用語 TDS＝紺 …）ので、グリッドで並んでも区別がつく
- 動画は「やること → なぜ → 上げると / 下げると味がこう変わる」の順で、絵が動いて見せる（温度計が上がる、粉が細かくなる、カップに溶けた粒が増える）

- 案A **ポスター**: 回ごとに背景の色がまるごと変わる。太い字とステッカー風の絵。グリッドでいちばん目立ち、区別もいちばんつく

- 案C **シネマ**: 黒い地に、話題の色で光る絵。高級感があり、今の暗い色調に一番近い

3 回分の中身（湯温を上げる / 挽き目を細かく / 用語 TDS）は見た目を比べるための見本で、文言は本番化の時にカリキュラム全 36 回ぶん作り直す。
絵は案を決めた後に、残りの話題（時間・量・注ぎ方・器具・水・氷など）の分も同じ描き方で足す。

作り方: `node scripts/render-directions.mjs`（`src/directions/`）。本番の動画にはまだ入っていない。

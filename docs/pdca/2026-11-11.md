- 抽出法の選択: `clever`（クレバードリッパー）。ローテーション使用 0 回、前日（11-10）のフレンチプレスとも違う。「浸して、甘いところで落とす」操作が今回のテーマ「抽出を止めるタイミング」と直結するので、理屈と操作が同じ画面で重なる。
- 前提の点検: なし。今日の原稿に専門用語は「成分」「酸・甘み・苦味」など、コーヒーを飲む人なら誰でも分かる言葉のみ。「クレバー」は表紙のバッジだけで、本文・読み上げには出ない（器具バッジは説明不要）。前提スライドは入れない。
- 図解の型 `graph`: 横軸「落ちる順」（最初 / 中盤 / 後半 / 最後）、縦軸「甘み」。点は 2→4→3→1 の山形で、帯 `zones` = 酸っぱい / 甘い / 苦い が区分の味を明示。マークは「中盤」= 甘みのピーク = 今日の止めどき。2026-10-28 の分析（伸びた回は目盛りで「自分の一杯の位置」と「区分ごとの味」を言う）に沿う構成。

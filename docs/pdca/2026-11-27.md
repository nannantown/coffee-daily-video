## 所感

今日の回はカリキュラム中級 第14回「未抽出ってなに？」の用語回（pillar=terms、固定）。抽出法は 14 日の使用回数が 0 のエアロプレスを選び、前日のペーパードリップから切り替えた。カリキュラムの下書き (`next-episode.mjs --json`) をベースに、word / ask / hook は一字も変えずに使用。初稿後の 5 人レビュー（agents）で 8 周回し、持ち越し以外の重い指摘ゼロで通過。

主な変更:
- topic を「酸が引き、甘みが出る」から「酸っぱく薄い味」に変え、未抽出の症状を表紙に出すことで、読み上げ側の「成分が出きる前に止まった」との対比を明示
- narration.title を「未抽出ってなに？酸っぱく薄い、成分が出きる前に止まった味です。」に拡張し、症状と仕組みの両方を一息で届ける
- 事実面: 「厚みが出る」「濃くなる」が SCA 出典範囲外との D 指摘を受けて、effect[0].taste は「酸が引き、甘みが出る」で確定。事実メモ #1 を SCA 抽出図の全軸対応（未抽出↔過抽出）に拡張し、メモ #4（酸味は先、甘みは遅れる）を追加
- 2026-10-28 発注の 3 区分地図型を踏襲: visual は graph で zones=[未抽出, 適正, 過抽出]、narration.visual で「短いと酸っぱく、ちょうどで甘く、長いと苦くなります」と 3 区分の味を 1 文で読み上げ。caption も「短いと酸、ちょうどで甘、長いと苦」に揃えた
- 場面2 motion は meter → dissolve に変更。粉から成分が溶け出す機序（原因）を描き、場面3 のグラフ（結果の地図）と役割分担が立つ
- narration.tips は「延ばしても酸っぱければ、挽き目も細かく。それでも薄ければ、お湯を高めに。」の段階式に書き換え、場面5 が hook（延ばす）の延長であることを音声で橋渡し。tips[0].problem も「延ばしても酸っぱい」に揃えて、画面でも階段を見せた
- `why` は「未抽出＝成分が出きる前に止まること」から「お湯に触れる時間が短いから」に変更。場面1 読み上げとの重複を減らし、場面2 画面に因果ラベルを立てた

## 戦略更新提案

- **場面2 テンプレの再設計**: `hook`（対処指示）と `why`（原因）が同じ場面に同居するため、見出し「なぜ変わる？」と画面上段の hook が噛み合わない。`print-script.mjs` の場面2 テンプレを「原因側だけに絞る」構成に変える PR を検討。effect 対も場面4 に集約して場面2 から外すと重複が解消する
- **用語回の表紙 topic 型**: 現状は他の用語回（フレンチプレス「味がブレにくくなる」等）と揃えた「症状／結果型」。一方で用語回の問いは「ってなに？」で定義を求めるため、cover に定義句が入っていないと読者が戸惑いやすい。`data/curriculum.json` の用語回を一斉に定義型に切り替える PR を検討
- **シリーズ初心者への前提の導入**: 「コーヒーに甘みがある」はスペシャルティ文脈では自明でも、一般視聴者には前提ではない。カリキュラム初級の前半（第1〜5 回あたり）で「コーヒーに甘み／酸味／苦味がある」の 3 味を明示する回を入れる、あるいは各用語回の冒頭に「まず前提」スライドでそれを示すオプションを人の PR で検討
- **判定軸「薄い」の曖昧さ**: 「薄い」は個人差が出やすい語。別回で「水っぽい／後味が残らない／舌に軽い」等の補助手がかりを揃える回を入れる余地あり
